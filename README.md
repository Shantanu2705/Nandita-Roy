# Nandita Speaks — Official Personal Branding & Professional Portfolio

World-class, premium personal branding and portfolio website for **Nandita Roy** under the brand **Nandita Speaks** ([https://www.nanditaspeaks.com](https://www.nanditaspeaks.com)).

Built with **Next.js 14 App Router**, **TypeScript**, and **Tailwind CSS**.

---

## 🌟 Overview & Key Features

* **Official Brand Identity**: Derives its visual language and color palette directly from the official Nandita Speaks tree emblem and logotype.
* **Warm Luxury Editorial Design**: Warm ivory (`#FFF9ED`), soft champagne (`#FFF3DC`), golden yellow (`#F4C84A`), amber (`#EFAE32`), and deep charcoal (`#29251F`).
* **Complete Editorial Architecture**:
  * **Homepage (13 Sections)**: Editorial Hero, Brand Statement, Meet Nandita Roy, Impact Stats, 3 Pillars of Expertise, MUN Fun & Beyond, 4-Step Training Journey, UN & National Recognition, Verbatim Endorsements, Media & Interviews, Photo Gallery Preview, Programs Preview, and Final CTA.
  * **About Nandita (`/about`)**: Comprehensive career history, UN ESCAP advocacy, theatrical productions, and educational philosophy.
  * **Programs & Courses (`/programs`)**: Two-phase structured curriculum (Foundation of Confident Speech & Multi-Lateral Diplomacy).
  * **Endorsements (`/endorsements`)**: Verified testimonials from corporate executives, principals, and delegates.
  * **Photo Gallery (`/photo-gallery`)**: Filterable photo gallery with full-screen Lightbox viewer.
  * **Video Gallery (`/video-gallery`)**: High-definition video gallery with modal player.
  * **Programs & Events (`/programs-events`)**: Conference timeline and interactive year filters.
  * **Contact (`/contact`)**: Form validation, direct WhatsApp redirect, telephone, email, and office hours.
* **Conversion & Engagement**: Floating Call and WhatsApp contact pills accessible on every page.
* **SEO & Metadata**: Complete OpenGraph, Twitter Cards, Sitemap, Robots, and Schema.org JSON-LD Person/WebSite metadata.

---

## 🚀 Technology Stack

* **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Components by default)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Icons**: [Lucide React](https://lucide.dev/)
* **Typography**: Playfair Display, Plus Jakarta Sans, Cormorant Garamond

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

---

## ☁️ Deployment on Vercel

1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset: **Next.js**
3. Build Command: `next build`
4. Output Directory: `.next`
5. Install Command: `npm install`
6. Click **Deploy**.
